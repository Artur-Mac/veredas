# REGRAS DO PROJETO VEREDAS (ANTIGRAVITY IDE)

1. **Design System Editorial:**
   - Respeite estritamente o `veredas-tokens.css` e o `docs/BRAND_GUIDELINES.md`.
   - `border-radius: 0px` universal.
   - Sombra dura `box-shadow: 4px 4px 0px #141413`.
   - Tipografia: `Instrument Serif`, `Plus Jakarta Sans`, `JetBrains Mono` (`tabular-nums`).

2. **Engenharia de Dados e Backend:**
   - Arquitetura de três camadas (Medallion): Bronze (anúncios brutos), Silver (Entity Resolution, deduplicação multi-portal), Gold (métricas periciais H3, SHAP Waterfall, score Veredas).
   - Zero dependências obrigatórias além de Python stdlib para garantir execução instantânea, com suporte a FastAPI / Uvicorn se presentes.

3. **Inteligência Hiperlocal do Recife:**
   - Auditoria cadastral ESIG Recife (verificação de metragem e habite-se).
   - Decomposição SHAP do preço justo vs sobrepreço sem lastro.
   - Resiliência a alagamento com cota altimétrica e marés de sizígia.
   - Orientação bioclimática (Nascente vs Poente e ventos alísios).
   - Simulação de rotinas e isócronas reais (Porto Digital, UFPE, Ilha do Leite, Boa Viagem).
