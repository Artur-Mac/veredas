# Research-to-implementation traceability

Version: 1.0 · 14 November 2026 · Supporting appendix to the official Vereda application plan.

This appendix covers every one of the **217 distinct PDFs** assessed in the [individual corpus review](../dados/literatura/avaliacao-do-acervo.md): **101 original papers and 116 urban papers**. It translates their existing dispositions into English and maps each paper to an implementation lane and an evaluable application. The inherited totals are **68 Apply, 106 Experiment and 43 Reference**. “Apply” identifies a useful method; it does not mean that the associated feature is implemented or validated. “Experiment” requires the stated data and comparison. “Reference” informs context, evaluation design or a decision to defer.

The underlying review used extracted text from all PDFs and targeted reading of decisive methods/results sections. This appendix is implementation traceability, not a new independent replication of every result. Existing paper titles and filenames are preserved so that the references stay auditable. A filename can be a catalog identifier rather than the publication's formal title. No paper's reported performance is treated as a local acceptance threshold.

The **Owning epochs** column assigns responsibility for evaluating the method. It does not require every candidate model to be deployed. The [official application plan](VEREDA-APPLICATION-PLAN.md) defines dependencies and acceptance.

Read the [integrated technical assessment](../dados/literatura/parecer-tecnico-integrado.md), [original catalog](../dados/literatura/manifesto.md), [urban catalog](../dados/literatura/urbanismo-nova-leva/CATALOGO.md) and [audit evidence](../dados/literatura/evidencias-do-parecer.json) for source context. The official plan controls execution order; a row here creates a candidate application or test, not an obligation to deploy an expensive model.
