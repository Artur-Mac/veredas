**Synthetic values.** G-COMPARE listing values (price, condo, IPTU, area) are synthetic test inputs placed on real public buildings to exercise arithmetic and decision cases. They are not observed offers, must not be imported into a person's saved notebook, and must not be reported as market evidence.
