# VE15 — Summary

VE15 chose one optional extension to answer the question that remains most often after a comparison. That is the decisive missing value Compare already names, such as an unknown condo fee that could flip which home to visit first. Under that question, the summary now shows "Já tem a resposta?": one numeric field (plus the period for IPTU) and one tap. The value is saved as "informado por você", the comparison is recomputed, and one sentence says what changed for the person ("Com esse valor, a ordem mudou: visite primeiro Casa Forte." or "A ordem não mudou: Graças continua na frente."). Before this, the same answer could only go to the visit script as free text, where it never changed the comparison. In the same fixture, that script has 6 questions and the condo fee is the 2nd. Alongside it, the existing optional features were inventoried without removing anything: 11 keep, 1 repair (free-text visit answers) and 3 defer. Five context needs were queued: three stay at their supported scale, and connectivity, auctions and any address-level data became research tasks rather than guessed building metrics.

The evidence is unit, rendered and regression testing, not people. Five unit tests cover field mapping, the IPTU period rule, invalid values and a monotonic check: raising B's condo fee never moves B ahead. A scripted browser run at 375 and 360 px with values 150 and 1200 passed 4/4. In each case the sentence was in view, the value persisted after reload, there was no horizontal scroll and no external request. The rendered check found two real defects, both now fixed. First, the sentence disappeared because the answered question closes its own box. Second, the shrunken card left the sentence above the viewport. The full suite (67 suites, 1,569 tests), typecheck, lint (0 errors) and the 50-step smoke test still pass. So the core works without uploads, accounts, sensors or permissions, and the privacy, backup and migration tests remain valid.

VE15 stays partial / iterate. The answer flow has not been timed with people (G-USER), and the document test (VE15.02) needs real building documents with exact pages. Native capture or sync has no device evidence; the scroll-to-sentence fix is web-only, and native relies on the status announcement. Next: time this flow against "Ajustar valores" in the G-USER paired task, and run VE15.02 when a participant brings a real balancete or ata. Then let a structured answer given in the visit screen recompute the comparison too. The next eligible epoch is VE16 (affordable updates and supported coverage expansion), which builds on the payload-split session's data loaders.
